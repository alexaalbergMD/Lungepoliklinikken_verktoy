# Lungepoliklinikken verktøy

Små nettverktøy for Lunge- og allergipoliklinikken, Barne- og ungdomsklinikken, St. Olavs hospital.

- `astmaplan.html`: astmaplan med preparater og doser etter alder.
- `vaeskeplan.html`: væskeplan ved omgangssyke, fyller ut `Omgangssyke_hjemreise.pdf`.

Sidene publiseres med GitHub Pages. De lagrer ingen pasientopplysninger.
